# Card Profile Design

Each card represents a synthetic cardholder with a normal spending pattern.

## Card Profile Fields
- card_id
- cardholder_id
- home_city
- home_state
- home_country
- home_latitude
- home_longitude
- usual_categories
- avg_amount
- amount_stddev
- usual_channel
- active_hour_start
- active_hour_end
- device_id
- ip_region

## Design Notes
- Each card has a stable home geography
- Each card uses only a subset of merchant categories regularly
- Each card has a typical transaction amount range
- Each card has a dominant transaction channel
- Fraud is generated by violating one dimension of the profile
